# Big Data, Bigger Bags — MIS Capstone Series

**Live case study:** https://tychfe34.github.io/Management-Information-Systems-Projects/

A six-project Management Information Systems capstone series built around **Big Data, Bigger Bags**, a fictional creator-management and brand-partnership agency. The series moves from a KPI framework through a Tableau evaluation model, a Salesforce CRM, real e-commerce funnel analysis, and finishes with **ConversionIQ**, a governed Responsible AI assistant design.

Built by a five-person MBA team: Frankie Velasquez, Deshan Liyanage, **Tyler Chaffee**, Jorge Ramos, and Jesús Gomez.

## The series

| # | Project | What it did |
|---|---------|-------------|
| 1 | Balanced Scorecard & KPI Framework | Defined 10 KPIs across financial, customer, internal process, and learning & growth perspectives for a content-creator dashboard |
| 2 | Tableau Creator Evaluation | Built a Partnership Readiness Index against a public YouTube influencer dataset to replace subscriber-count-driven decisions |
| 3 | Salesforce CRM | Designed a minimum-viable data model (Account, Contact, Case) and workflow for brand-partnership intake |
| 4 | Digital Analytics Mini-Deliverable | Diagnosed funnel drop-off (87.6% View Item → Add to Cart) on the Google Merchandise Store synthetic dataset |
| 5 | Pivot Table Analysis | Layered monthly, category, and product-level pivot views onto the same funnel data |
| 6 | ConversionIQ — Responsible AI Capstone | Designed a two-mode AI assistant (Monday report + bounded chat) with 14 Responsible AI risks mapped to specific operational controls |

## Dataset

The Google Merchandise Store dataset (Projects 4–6) is synthetic data generated from real GA4 distributions, covering November 2020 – January 2021. Full field documentation is in the dataset README PDF above.

## AI Use Statement

Generative AI tools (ChatGPT and Claude) were used throughout the series for brainstorming, refining KPI definitions and formulas, structuring written sections, and — for Project 6 specifically — the report's visual design and PDF layout. All analytical decisions, KPI selections, and written content were developed, reviewed, and approved by the team. Full statements are included in each individual project deliverable.
